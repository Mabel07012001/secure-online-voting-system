📋 Descrição do Sistema

O Online Voting System é uma aplicação web desenvolvida para facilitar processos de votação de forma segura e eficiente. Permite que utilizadores se registem, façam login e votem electronicamente. O sistema garante a integridade do processo através de encriptação e mecanismos de autenticação, oferecendo uma plataforma conveniente e acessível.

🔐 Autenticação OTP & Segurança

A autenticação OTP (One-Time Password) é uma medida de segurança usada para verificar a identidade dos utilizadores antes de acederem ao sistema. Os utilizadores recebem um código único via email, que devem introduzir para completar o processo. Isto adiciona uma camada extra de segurança contra acessos não autorizados.

✅ Benefícios do Sistema

O sistema oferece várias vantagens sobre métodos tradicionais de votação. Proporciona uma plataforma mais conveniente e acessível, especialmente para aqueles que não podem comparecer fisicamente às urnas. Além disso, garante a integridade e confidencialidade do processo, tornando-se uma solução fiável para processos democráticos modernos.

🛡️ Informação de Segurança

O sistema implementa medidas robustas para proteger a integridade e confidencialidade do processo de votação, incluindo encriptação ponta-a-ponta, protocolos de autenticação seguros e auditorias regulares de segurança.
